# Virtual String

Браузерный музыкальный инструмент: создавай виртуальные струны между пальцами, сохраняй их в сцене и играй жестами через веб-камеру.

## Запуск
Открой GitHub Pages: https://andreybin742-cmd.github.io/WallTrace/ в актуальном Chrome или Safari. Разреши доступ к камере. На iPhone/iPad сайт должен быть открыт по HTTPS (GitHub Pages это обеспечивает). Нужен интернет для загрузки MediaPipe с CDN.

Для локального запуска из папки с `index.html` выполни `python -m http.server 8000`, затем открой http://localhost:8000.

## Как пользоваться
1. Нажми «Включить камеру» и покажи обе руки.
2. Разведи указательные пальцы — пунктирная линия показывает текущую заготовку.
3. Нажми «Зафиксировать струну». Теперь она остаётся на экране, даже если убрать руки.
4. Повтори, чтобы создать несколько струн.
5. Проведи кончиком другого пальца поперёк сохранённой струны, чтобы извлечь звук.
6. Выбери струну в списке, настрой её натяжение ползунком или удали.
7. Нажми «Проверить звук», чтобы проверить аудио отдельно от распознавания жестов.

## Важно
Это экспериментальный 2D-прототип. Струны закрепляются в координатах изображения камеры, а не в настоящем 3D-пространстве. На мобильных устройствах качество распознавания зависит от камеры, освещения и производительности. Звук генерируется Web Audio API в браузере.
