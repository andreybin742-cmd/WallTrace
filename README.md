# WallTrace

Тестовый мобильный веб-прототип для разметки коммуникаций на изображении стены.

## Запуск на iPhone
После публикации GitHub Pages откройте сайт в Safari и разрешите доступ к камере. Камера требует HTTPS.

## Ограничения прототипа
- Линии рисуются поверх видеокадра и сохраняются в браузере.
- Нет распознавания поверхности и устойчивого AR-якоря между сессиями.
- Приложение не обнаруживает скрытые кабели или трубы и не является средством безопасности при сверлении.
